            操作指南
            
什么是分发节点？如何 4 步新增部署（支持 SSH 全自动 / 无公网 NAT·FRP 脚本）

          

          
        

        

          

            什么是「分发节点」？ 分发节点是部署在源端/中转机上的服务程序（relay-agent-a）：它在本机 127.0.0.1:18081 接收业务方或采集器推送的文件，并通过 TLS 1.3 加密端口（默认 8443）高速分发给所有内网接收节点；文件确认安全落盘后自动清理中转缓存。
          

          

            
            
          


          

            

              
1一键 SSH 激活上线

              
点击「一键部署分发节点 (SSH)」，填入公网 IP 与节点 ID，预检后一键激活并自动扫描本机全部物理盘。

              
            

            

              
2网页勾选数据盘（多盘并发）

              
节点上线后点「选择数据盘」（可点刷新实时扫新挂硬盘），勾选 1 块或多块盘自动建 <盘>/relay-cache 目录，支持多盘并发传大文件。

            

            

              
3强制水位防写爆保护

              
无论数据盘或系统盘 / 均强制启用安全水位（≤85% 且至少预留 10GB），超水位自动拒收/切盘，绝不撑爆系统。

            

            

              
4本机免鉴权推流并随时热控

              
业务方在分发机本机直接推送 http://127.0.0.1:18081（免 Token）；日常可随时点「暂停/启动」或热增减缓存数据盘。

            

          


          

            

              
1登记分发节点（无公网先做映射）

              
无独立公网 IP 时，先用 NAT/FRP 将 TCP 8443 映射到公网可达地址；点「+ 手动注册分发节点」填节点 ID 与映射地址（无需先填磁盘）。

              

                
                
              

            

            

              
2执行激活脚本上线并扫盘

              
点击该节点「安装脚本」→「复制一键执行命令」粘贴到目标机回车，自动签发证书并上线扫描所有物理盘（未选盘前不接收上传）。

            

            

              
3网页刷新并勾选数据盘激活

              
列表亮起「⚠ 待选盘 · 未激活」后，点显眼的「⚡ 选择数据盘并激活」，勾选 1 块或多块盘自动建 relay-cache 目录并立即激活！

            

            

              
4验证运行与日常免 SSH 管控

              
激活后即可多盘并发缓存传输大文件；新插硬盘挂载后点「刷新物理盘」直接勾选用上，随时可暂停/启动。

              

                sudo systemctl status relay-agent-a --no-pager

            新手必看 · 无需公网 IP
            
什么是接收节点？如何 4 步接入一台新的内网落盘机器

          

          
        

        

          

            什么是「接收节点」？ 接收节点就是你本地机房 / NAS / 用来最终存文件的 Linux 硬盘服务器（上面运行 relay-agent-b 客户端）。它完全不需要公网 IP，也不需要路由器端口映射或开放任何入站防火墙——只要机器能正常访问外网 HTTPS，就会主动向中心拉取任务并高速写盘，落盘校验完成后自动通知上游释放空间。
          


          

            

              
1登记新接收节点（免填磁盘路径）

              
点击下方按钮给本地存储机/NAS 取个编号（如 nas-02）和备注名，选好下载项目即可，完全不用提前手敲硬盘目录。

              
            

            

              
2执行一键激活脚本上线扫盘

              
创建后点「生成一键安装脚本」→「复制一键执行命令」，粘贴到接收机终端回车。节点 3 秒上线并自动扫描机器上全部物理盘（未选盘前暂不下载）。

              

                curl -kI https://.../healthz
                
              

            

            

              
3网页刷新并勾选数据盘激活

              
列表亮起「⚠ 待选盘 · 未激活」后，点显眼的「⚡ 选择数据盘并激活」（新插硬盘可点刷新物理盘），勾选 1 块或多块盘自动建 relay-delivery 目录，支持多盘并发写盘！

            

            

              
4强制水位保护 & 免 SSH 热控

              
无论数据盘还是系统盘 / 均强制启用水位保护（≤90% 且保留 ≥10GB）；后续热增减硬盘、切项目、暂停/启动、热升级全在网页完成。

              

                sudo systemctl status relay-agent-b --no-pager
